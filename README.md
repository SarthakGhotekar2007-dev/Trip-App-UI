# Trip App UI - Flutter Practice

A simple Flutter practice project to build a Trip App UI based on an Adobe XD design. 

## 🌟 About
This is my Flutter UI practice project for learning modern app design. It implements a beautiful Trip Planning UI, including calendar and map elements.

## 🚀 Built With
- [Flutter](https://flutter.dev/)
- [table_calendar](https://pub.dev/packages/table_calendar)
- [flutter_map](https://pub.dev/packages/flutter_map)
- [lottie](https://pub.dev/packages/lottie)
- [google_fonts](https://pub.dev/packages/google_fonts)

## 📸 Design Reference
The UI is inspired by this Adobe XD design: [Trip UI Design](https://xd.adobe.com/view/7d1807c9-69e8-43d1-9ed7-be3365df9be7-284b/)

## 🛠️ Getting Started
To run this project on your local machine:
1. Clone the repository
2. Run `flutter pub get`
3. Run `flutter run`
